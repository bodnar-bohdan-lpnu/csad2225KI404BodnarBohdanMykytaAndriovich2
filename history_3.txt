Етап 3. Впровадження юніт-тестування (Unit Testing)
Для цієї роботи ми будемо тестувати просту функцію, а для фреймворку використаємо
Google Test.

Створення модуля для тестування:
○ Створіть файл math_operations.h та math_operations.cpp у корені
проекту.
○ У math_operations.h за допомогою Copilot створіть функцію int
add(int a, int b);
Створення файлу юніт-тестів:
○ Створіть новий каталог tests. У ньому створіть файл unit_tests.cpp.
○ Напишіть юніт тести за допомогою Copilot
Оновлення CMakeLists.txt:
○ Використовуйте Copilot для додавання підтримки Google Test у ваш
CMakeLists.txt.
○ Далі, за допомогою Copilot, додайте інструкції для створення тестового
виконуваного файлу та запуску тестів
